How it works. Each round a sparse Kenyon-cell code represents the cue; learned KC→MBON weights set a bet-drive; a win fires reward-dopamine, a loss fires pain, and both rewrite the weights. Sustained losses deepen a slow mood; a withdrawer gets too sad and sits out (and often survives), a chaser keeps going. ·This live page runs a fast behavioral model of that circuit so it can play forever; the full spiking connectome (real FlyWire wiring, ~140k neurons) runs in Python.
